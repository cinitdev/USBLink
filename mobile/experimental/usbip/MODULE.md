# USBLink Mobile 0.3.36 · USB ADB

0.3.36 修复 VPN 分流下模块反向连接电脑误走 singBox 代理网卡：检测 socket 显式绑定原 USB/IP 入站连接的 USBLink 本地地址。与 Windows 0.3.21 配套时，电脑手动连接遇到短暂在线探测失败会只读等待 6 秒。网络恢复后可核实并释放旧 USB 会话；仍由用户发起单次连接，不自动挂载或重复 attach。配对、共享偏好和健康会话保护不变。

0.3.34 把守护进程日志分开：`logs/daemon.log` 只写模块自己的 JSON 错误，MIUI/HyperOS 在打开 SQLite 时打印的框架堆栈（例如缺少 `/data/system/theme_config/theme_compatibility.xml`）写到 `logs/daemon.stderr.log`，不再混在一起。状态里的版本号改为读取实际 `module.prop`。

0.3.33 恢复 `config`／`history`／`runtime`／`logs` 分目录，并去掉启动阻断：每次启动只做一次尽力整理，永远不中止启动。只有确认没有模块进程时才搬动文件；搬不动就留在原处继续用。新旧位置内容不同时保留上一版实际使用的根目录文件为当前数据，旧的归档到 `backups/legacy`；内容相同才删除旧副本。SQLite 与 `-wal`／`-shm`／`-journal` 成组搬迁；若搬迁中断导致分开，守护进程打开数据库前先合并。旧 JSON 只归档到 `backups/legacy`，不读取、不导入。

0.3.32 是过渡版本：移除了会导致 K40 无法启动的启动前强制迁移，数据暂时平铺在 `/data/adb/usblink/`。

0.3.31 修复真我 GT5／Android 16 历史页无法打开数据库：在 SQLite 打开前明确指定 WAL 和 FULL，避免 ROM 默认同步配置读取异常。已在该机独立临时目录验证真实 Android SQLite 读写、连续去重及重开保留；没有删除原历史文件或重启运行中的共享。完整 WebUI 更新仍需安装新版模块。详见 [验证记录](../../docs/history-android-0.3.31-validation.md)。

0.3.30 修复 USB 调试已开启、但 adbd 已停止时共享启动被提前拒绝的问题。先核验调试授权、保存恢复记录并建立端口防护，然后启动一次系统服务；实际监听未就绪时保持等待。关闭共享恢复原运行／停止状态，服务正在切换或状态未知时明确提示。没有放宽认证或防护，也没有自动重试、USB 重新挂载。真我 GT5／Android 16 的截图问题已定位代码路径，修复尚未在该机实测。

0.3.29 修复历史脱敏误判：普通 `usblink-` 文件名、路径、安装包和网络名完整显示，真正的 `USBLINK1-` 配对码及明确凭据继续隐藏。旧记录已替换的原文无法恢复，修复对新记录生效。

0.3.28 曾新增数据目录整理（`config`／`history`／`runtime`／`logs` 分目录）。该功能在 0.3.28～0.3.32 之间因启动前强制迁移导致无法启动；0.3.33 保留分目录，但迁移改为不阻断启动的尽力整理。

通过 USBLink 网络连接手机，让电脑已有的 ADB / Android Studio 调试、安装应用和传输文件。作者：**一只小柒夏**。

## 设备与管理器

要求 **Android 12+（API 31+）、ARM64、Root**。同一个 ZIP 支持 Magisk、APatch、KernelSU；Magisk 要求 20.4+，通过自行安装并授予 Root 的 KsuWebUI 打开界面。APatch／KernelSU 可使用管理器内置 WebUI。后端为 DEX JAR + app_process，没有独立 USBLink APK，不自动下载 WebUI APK。

用户于 2026-11-09 反馈：已在**骁龙和天玑手机**上测试可用，因此从 0.3.25 起移除模块及安装包的实验标识。具体 ROM／管理器组合仍以设备实测为准，不限定手机品牌。

## 本版变化

- 名称为 USBLink Mobile · USB ADB，安装包为 `USBLink-Mobile-0.3.36-usb-adb-arm64.zip`，元数据、后台状态与 WebUI 版本一致。
- 保留 0.3.24 后台调用修复：支持的宿主使用异步接口，共享启动／状态同步期间可切页；旧 exec-only 宿主建议更新。历史长输出展开时渲染，刷新保留展开状态。
- 历史改用 **SQLite**，最多保留 **200 条**，每页默认显示 **50 条**。列表仅取摘要，展开时查询完整命令和返回。只记录实际 ADB 命令，过滤 track-app、sync 通道、JDWP 与文件探测等内部协议。忽略 shell／shell,v2 等协议包装，同一电脑连续发送相同命令只保留第一条及其返回；后台协议不打断去重，不同实际命令打断后可再次记录。已有 SQLite 历史也会按新规则整理。保留 USB 调试检测、首次点击共享修复、多设备连接及桌面更新后旧会话释放。
- adbd Root 运行模式及实现已删除。本机 WebUI Shell Root 检测只反映管理器授权，不代表远程 ADB 权限。

## 使用

1. 在 Magisk／APatch／KernelSU 安装 ZIP，按管理器提示重启。升级保留网络、配对码和共享偏好；旧 JSON 历史不导入，已有 SQLite 数据库保留有效命令并整理；从旧 TCP 模块升级不会自动开启 USB 共享。
2. 开启普通 USB 调试，无需无线调试。电脑安装 USBLink 0.3.21 与 usbip-win2 0.9.8.0 或更新版本。旧 Windows 0.3.11 起可连接模块；更新后旧会话释放需要新版两端配合。
3. 手机和电脑加入**同一个 USBLink 网络**，在手机开启“共享这台手机”。
4. 电脑连接页选择手机，点击“连接设备”；首次在手机允许 RSA 调试授权。电脑现有 ADB 经 USB 接口识别手机，无需 adb connect。
5. 电脑可断开单个设备。手机关闭共享会撤销会话、断开网络并恢复原调试端口，保留配对码。再次开启无需重新配对或重启手机；重启遵循保存的开关。电脑掉线后仍需手动连接。

启停共享可能重启手机系统 adbd，短暂中断其他调试。模块保留认证、SELinux、USB 调试设置和原端口，不修改电脑 ADB，不管理其他工具赋予的 adbd Root 权限。从曾注入 adbd Root 的旧模块升级，需要重启一次清除旧进程与临时挂载。

## 历史与隐私

底栏为设备 / 连接 / 历史 / 设置。历史记录模块观察到的请求、时间、来源地址及关联返回，按安装应用、应用管理、Shell、文件、调试、系统和网络分类，支持全量搜索、分页、静默同步与确认清空。

历史数据库位于 `/data/adb/usblink/history/adb-history.db`，可能伴随 SQLite 的 `-wal` / `-shm` 文件，不上传、不写浏览器存储。首次使用 SQLite 时从空数据库开始，不读取或导入旧 JSON，旧文件只归档到 `backups/legacy`，不解析其内容。升级现有 SQLite 时过滤内部协议、合并可确认相同的连续命令，保留首次返回；原始参数已脱敏或截断的旧记录不据此猜测相同。返回最多 4 KiB，超出标注截断，显示可获得的 stdout、stderr、退出码或文件协议状态。收到请求或通道关闭不等于成功。电脑原始参数和本地路径不可见时明确说明；旧输出不补造，不重放命令。认证材料、文件内容、交互按键及已识别的二进制返回不采集；可识别凭据脱敏，返回文本仍可能含个人信息。关闭共享保留历史，清空不影响连接。

## 支持范围与验证

电脑枚举为 **Android ADB Interface**。目前不提供 **MTP 便携设备、资源管理器浏览手机存储、Fastboot、外接 U 盘或外接手机共享**。USB 枚举可能触发 Windows 正常提示音。

采用现有 `18d1:4ee7` 描述符完成驱动互通；更名不改变设备协议、USB 身份或驱动兼容性，也不表示取得独立 USB 标识或驱动认证。

用户骁龙／天玑的实测反馈与开发检查分别记录。此前 K40 / Android 12 / APatch 已验证驱动、RSA、64 MiB 双向传输及清理。本次 SQLite 改动进行了真实 SQLite 主机定向检查，未刷入手机验证性能。后台切页验证见 `mobile/docs/webui-response-0.3.24-validation.md`，历次修改见仓库 `CHANGELOG.md`。省电优化没有实际电量测量结论。

## 构建

`powershell -NoProfile -ExecutionPolicy Bypass -File mobile/scripts/build.ps1 -UsbAdb`

输出 `release/USBLink-Mobile-0.3.36-usb-adb-arm64.zip` 及 SHA256 文件。旧参数 `-ExperimentalUsb` 仍作为别名兼容。源码目录和内部协议标识保留原路径以兼容旧电脑、配对及共享偏好。不加 USB 参数时构建 TCP 开发模块；两种包使用同一模块 ID，不能同时安装。
