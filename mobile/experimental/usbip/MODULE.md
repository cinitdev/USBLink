# USBLink Mobile 0.3.12 USB ADB 实验模块

0.3.12 包含启动恢复修复：运行记录损坏时，在持有启动锁并确认无模块进程后，备份损坏记录再恢复后台。配对、共享偏好、历史和调试恢复记录均保留。相关脚本已在 K40 / Android 12 的 0.3.11 上热修复并验证后台恢复；本 ZIP 尚未重新刷入测试。模块数据目录为 `/data/adb/usblink/`。

这是同一模块 ID 的实验升级包，不是此前的 TCP 转发模块，也不是完整 USB 手机模拟。

0.3.11 补充修复路由检查误断开：读取时限 4 秒，单次失败或空快照后只读核实；兼容等价规则格式，添加规则只执行一次并读取实际结果。确认失败仍关闭共享，区分查询失败、路由缺失和冲突；不自动重挂载。定向回归通过，K70 / Android 15 尚未实测。

0.3.10 修复状态查询失败导致的 `NETWORK_UNAVAILABLE` 误断开：原网络进程、同一虚拟网卡／地址与路由均实时确认正常时，保留当前 USB 连接；中继／设备列表查询失败显示“状态待确认”，不复用过期在线结果。实际网络失效仍撤销会话，并区分进程、网卡和路由故障；没有自动重新挂载。主机回归通过，K70 / Android 15 真机效果尚待验证，详见 [网络修复验证](../../docs/network-observation-0.3.10-validation.md)。

保留 0.3.9 的 **Magisk + KsuWebUI** 支持，与 APatch / KernelSU 共用同一个 ZIP。补齐 Magisk 安装识别、管理器自带 BusyBox 路径、WebUI 文件权限与授权提示；保留所有 0.3.8 功能。要求 Android 12+、ARM64；Magisk 20.4+。Magisk 用户在 Magisk 刷入模块并按提示重启后，自行安装并授权 [KsuWebUI](https://github.com/KOWX712/KsuWebUIStandalone)，在其中选择 USBLink。APatch／KernelSU 继续从管理器打开 WebUI。

模块不会下载或安装 APK。普通浏览器不能控制服务，KsuWebUI 必须获 Root 授权；关闭 WebUI 不影响后台共享。已完成主机兼容测试与打包，尚未在 Magisk／KernelSU 真机刷入验收，见 [验证记录](../../docs/root-managers-0.3.9-validation.md)。

0.3.8 新增“设置 → ADB 权限 → ADB Root 权限”。偏好默认开启，关闭或开启后重启手机仍保留选择；系统完成启动且 adbd 就绪后应用。日常切换无需重启手机，但需要重启系统 adbd，会断开已有 USB 和远程调试，电脑需手动重新连接。界面分别显示开关偏好和实际进程权限（Root UID 0／普通 UID 2000／待确认），确认失败保留错误，不自动重复切换或重挂载。

**手机有 APatch / KernelSU Root 不代表系统 adbd 支持 Root。** 此功能只使用 ROM 支持的系统 adbd 属性，不替换二进制、不修改 RSA 认证、SELinux 或开发者选项开关。量产 ROM 可能不支持，界面会说明并保留普通权限共享；不能保证 K40、K70 或任意品牌 ROM 都可生效。关闭 Root 后若无法确认普通权限，远程共享会暂停。

Root 偏好与共享开关独立：关闭共享仍断网并保留配对信息，Root 开关不会单独开启网络。停止模块时尝试恢复模块接管前的临时 Root 属性与权限；遇到外部修改或恢复失败时保留记录并报错。0.3.8 已通过主机生命周期、协议测试和 WebUI 预览，**尚未刷入真机验证 Root 切换及重启恢复**；见 [验证说明](../../docs/adb-root-0.3.8-validation.md)。

0.3.7 新增“连接 → 远程 ADB 历史记录”。自动显示通过模块转发的 shell / exec 命令、应用管理服务请求及上传／下载文件路径，包含时间与来源网络 IP；最多保留 200 条，重启后保留，可查看更早记录和确认清空。记录保存在手机 Root 私有目录，不上传到外部服务，不写入浏览器存储或常规诊断日志。命令参数可能含隐私，配对码和可识别的常见凭据参数会隐藏，但无法保证识别所有自定义敏感参数。

历史表示**已转发请求，不代表执行成功**。无法还原电脑命令行中的全部 `adb` 参数；`adb devices` 等电脑本地操作、绕过模块的连接及交互式 shell 内逐行输入均不记录。不保存认证材料、文件内容或命令输出。每条内容最多 512 个字符，超长内容截断；观察到不支持的协议会提示记录不完整，数据转发仍按原逻辑继续。异步合并保存避免在传输线程写磁盘，突然断电或强制终止可能丢失最近约 1 秒尚未落盘的记录。关闭共享保留历史，清空不会断开连接或重启 adbd。此次仅通过主机协议／存储测试和 WebUI 预览，尚未刷入真机；见 [验证说明](../../docs/history-0.3.7-validation.md)。

0.3.6 修复上传受阻时 USB 请求分发被同步写入占住的问题。现在使用单独、有界且保序的上传队列，读取与取消请求仍可继续处理；只有写入完成才确认对应请求，不增加自动重挂载。设备／连接页保留最近一次意外中断的原因与时间，区分电脑连接结束、手机 adbd 中断、网络撤销等，诊断不包含配对码、命令或传输内容。已在主机测试中复现旧版阻塞并验证修复；此次 K70 0.3.5 的亮屏双向 64 MiB 测试均成功，但上传时其他 ADB 查询超时，未复现实际掉线；0.3.6 尚未在 K70 刷入验收。

0.3.5 修复 USB 共享监听未开启地址复用的问题：网络恢复或重新开启共享时，旧连接的 TIME_WAIT 可能阻止重新绑定 TCP 3240，导致 `EADDRINUSE` 并暂停共享。绑定失败会立即释放资源，真实端口冲突显示具体端口；不抢占其他服务、不自动重挂载电脑 USB。保留下面 0.3.4 的断网省电行为。此次修复来自 K70 / Android 15 / 0.3.4 的反馈，主机回归测试及 Linux 套接字复现已通过，尚未在 K70 复测。

0.3.4 中，共享开关同时控制网络。关闭共享会停止 EasyTier、电脑在线检测和远程会话，保留配对码；再次开启时连接原网络，无需重新配对或重启手机。关闭时创建／加入网络只保存配置，“退出网络”才会清除配对。重启后遵循已保存的共享开关。

空闲时不轮询 EasyTier、不重复恢复调试配置，后台状态观察由每 2 秒改为每 5 秒；共享时保留必要的防护检查频率。本地 WebUI 管理服务仍在运行，无法保证零耗电，实际待机耗电尚未进行真机测量。

0.3.2 修复开启共享后重启手机，因系统尚在初始化防火墙而暂停共享的问题。共享开关保持开启，等待 Android 完成启动且网络规则稳定后，再执行一次服务启动；等待期间可以关闭开关。完整防护规则被系统插入的规则挤到后方时，后台仅修正优先级，不重启 adbd、不重连 USB；缺失规则或持续外部干扰仍会暂停并说明问题。

## 使用

1. 在 Magisk／APatch／KernelSU 安装本 ZIP，按管理器提示完成安装和首次重启。Magisk 使用已获 Root 授权的 KsuWebUI 打开模块，APatch／KernelSU 可直接打开内置 WebUI。升级保留组网配置与同一 USB 实验通道的开关偏好；从旧 TCP 版升级时不会自动开启新 USB 通道。
2. 在手机开发者选项开启普通 USB 调试。无需开启无线调试。
3. 电脑安装配套 USBLink 0.3.12（0.3.11 仍兼容），并使用 usbip-win2 0.9.8.0 或更新版本。
4. 手机和电脑加入**同一个** USBLink 网络。在手机 WebUI 开启共享。
5. 电脑“连接”页选择手机，再点击“连接设备”。首次使用需要在手机确认 RSA 授权。电脑现有 ADB 会通过 USB 接口发现设备，不运行 `adb connect`。
6. 电脑可断开单个设备；手机关闭共享会撤销全部本机 USB ADB 会话、断开加密网络，恢复模块接管前的调试端口。配对码与开关状态保留，日常启停无需重启手机。掉线不会自动重挂载。

启停共享会重启手机系统 adbd，可能短暂中断已有调试。模块保留系统认证、SELinux、USB 调试开关和原有端口配置，不修改桌面 ADB。

## 已验证范围

独立试验已在 Redmi K40 / Android 12 / APatch 与 Windows usbip-win2 0.9.8.1 上验证驱动绑定、RSA 认证、64 MiB 双向传输和清理。模块整合的自动测试结果见本仓库验证记录；不得把独立试验描述成刷入此 ZIP 后的真机验收。

Windows 会出现 Android ADB Interface。**没有 MTP 便携设备、文件管理器盘符、Fastboot、U 盘共享或外接手机共享。** Android Studio 安装 APK 尚未作为真机验收项。USB 枚举仍可能触发 Windows 正常设备提示音。

实验使用 `18d1:4ee7` 进行驱动互通，不代表已取得产品 USB 标识或通过通用驱动认证；该代码和标识仅在显式实验构建中纳入，默认正式模块构建不包含它们。本模块随 GitHub v0.3.12 正式发布分发，但上述 USB 功能仍属实验范围，发布渠道不代表产品级认证。

## 构建

`powershell -NoProfile -ExecutionPolicy Bypass -File mobile/scripts/build.ps1 -ExperimentalUsb`

不加 `-ExperimentalUsb` 仍构建原 TCP 模块。安装相同 ID 的模块会替换现有模块；回退 TCP 版后需在 WebUI 关闭共享重置偏好，再自行开启。
