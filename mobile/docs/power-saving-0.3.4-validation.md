# Mobile 0.3.4：共享关闭后断网

日期：2026-10-08。本地模块构建，兼容 Windows 0.3.11；本轮没有连接、刷入或重启真实手机。

## 行为

- 关闭共享同时撤销 USB/TCP 会话和认证在线监听，停止模块拥有的 EasyTier 子进程并清理网络规则。停止确认失败保留错误和清理身份；即使恢复调试配置失败，也继续尝试断网。
- 配对配置不删除、不重建，开关前后的配对码完全一致。只有明确退出网络会删除配置。关闭时创建／加入网络及修改中继仅保存配置，不启动 EasyTier。
- 重新启用使用保存的网络，保持 Android RSA 授权和已有防护流程；不调用桌面 ADB，不自动重挂载 Windows USB。
- 开启偏好在重启后恢复，关闭偏好在重启后保持断网。本地 Root 控制服务仍然可用。

## 可确认的开销变化

| 活动 | 0.3.3 | 0.3.4 |
| --- | --- | --- |
| 关闭共享后的 EasyTier | 继续联网 | 停止，无网络心跳或组网查询 |
| 关闭共享后的调试恢复 | 每次状态循环调用 | 确认完成后不重复调用；失败等待明确重试 |
| 正常关闭时的后台观察／快照 | 每 2 秒 | 每 5 秒 |
| 共享及准备阶段 | 每 2 秒 | 保留每 2 秒及相同的防护校验 |
| 守护循环读进程信息 | 外部 `cat` | shell 内建读取 |
| 日志大小检查 | 每 2 秒 | 每 30 秒 |

WebUI 前台共享时每 2 秒、关闭时每 5 秒静默读取；进入后台停止页面轮询，返回立即读取。保留状态文件的启动身份和 10 秒过期校验；改变开关后立即唤起后台观察，旧定时任务不会建立第二条循环。

这些是代码路径和主机测试结果，不是电池测量。没有测试 CPU 占用、整机深度睡眠占比或每小时耗电；不能据此保证某个耗电百分比。本地管理进程和基础监督仍然存在，开启共享时网络、加密和数据传输也仍有开销。
