# Mobile 0.3.22：请求与手机返回验证

本文件记录当时构建的行为。0.3.22 误将历史保存上限设为 100 条；用户澄清后，0.3.23 已恢复保留 1000 条并改为每页显示 100 条。请使用 0.3.23，见 history-page-0.3.23-validation.md。

日期：2026-11-08。交付 USB ADB 实验模块，Windows 维持 0.3.19；TCP 开发源码同步至 0.2.12。

## 行为与边界

- 默认保留最近 100 条记录，读取旧文件时保留最新 100 条有效记录并异步保存；不会清空整份旧历史。旧记录未采集的输出不补造，重新载入的未完成请求标为中断。
- 按传输会话与 ADB 流 ID 关联命令、标准输出／返回文本、标准错误与实际退出码。Shell v2、ABB 使用结构化返回；legacy shell、exec、abb_exec 的文本通道关闭不被误记为成功。
- SYNC 上传／下载记录 OKAY、FAIL、DONE 及可解析的文件元数据，跳过 DATA 文件载荷。认证数据、APK 输入、交互式逐键输入／回显及识别出的二进制输出不保存。
- 每条返回的 stdout + stderr 合计最多 4096 字节。超过仍继续观察退出码、标注截断，不阻断传输。UTF-8 分片保留正确边界，移除终端控制序列并隐藏可识别的凭据。
- 请求保留设备可观察到的参数并显示可读 adb 表达；手机无法还原电脑路径、设备选择参数、完整主机调用或绕过模块的命令。不回放命令，不新增自动挂载或桌面 ADB 进程。
- 结果更新增加历史 revision，已有请求的返回变化也触发静默刷新；全量搜索涵盖已保存的输出。清空或轮转后到达的旧结果不能复活已删除记录。
