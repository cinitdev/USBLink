# Mobile 0.3.16 历史优化验证

日期：2026-11-04。桌面程序维持 0.3.17，本次交付手机实验模块 ZIP。

## 行为

- 被动记录模块已经转发的 ADB OPEN 请求及 SYNC 文件元数据；APK 数据流、AUTH、命令输出和交互式 Shell 输入仍不采集。不增加其他 ADB 服务、重挂载或系统命令执行。
- `AdbRequestType` 根据服务参数区分安装、创建会话、写入 APK、提交／放弃、增量安装、卸载及其他应用管理请求；识别 shell / exec 的 pm、cmd package 与 NUL 分隔的 abb / abb_exec 参数。调试、系统、文件、网络请求单独分类，未知服务保留原请求。
- 分类属于请求用途判断，不证明执行成功。复杂 Shell 脚本仅保留传入命令文本，不解析执行分支或脚本内容；不能还原电脑本地参数或未经过模块的请求。
- 最近 1000 条轮转，每条原文仍最多 512 字符，分页 20 条，文件读取上限 4 MiB；升级读取旧格式时补分类，保留旧记录。查询匹配全部保留记录，结合类别、关键词、游标与 epoch 防止串页。清空改变 epoch，过期查询不能恢复记录。
- UI 保留 AppOpt 布局；最新筛选结果由既有状态变化触发只读更新，没有独立轮询定时器。离开页面、清空与重置筛选后的迟到响应被忽略。历史仍在 `/data/adb/usblink/adb-history.jsonl`，不写 Web Storage。

## 定向检查

- `AdbHistoryTestMain` 51 项通过：安装协议变体和阶段、NUL 参数、引号与 su 包装、普通 echo 不误识别安装、未知服务、流式 APK 内容排除、原始字节不变、SYNC v1/v2 分片、1000 条轮转／重载、旧格式升级、跨页全局搜索、筛选游标、脱敏、清空／过期响应、保存失败和回环转发。
- WebUI history / api / request-flow 共 22 项通过，包括全局搜索旧 APK、分类标签、请求串行和清空后旧快照隔离。
- 浏览器显式示例验证安装分类、安装阶段标签、搜索 `older-release.apk` 命中 2 条（包含最新 20 条以外的记录）及 393px 显示。示例数据不来自手机。
- `build.ps1 -ExperimentalUsb -SkipTests` 完成生产 Java / DEX / WebUI 打包；核对 ZIP 版本与作者、DEX 分类代码、包内 WebUI 与 dist 逐字节一致、ZIP 完整性和 SHA-256。

没有运行全套生命周期测试，没有刷入真机或执行实际 adb install。本次验证不能替代 Android Studio / 不同 ROM 的真机安装覆盖验收。
