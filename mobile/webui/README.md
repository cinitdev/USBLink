# USBLink 手机 WebUI

0.3.25：去掉界面中的实验版标识，版本显示与模块包同步。用户反馈已在骁龙与天玑手机上测试可用；功能范围仍为 USB ADB，暂不支持 MTP、Fastboot 与外接 USB。

0.3.24：原生调用优先使用检测到的四参数 `ksu.spawn(command, argsJson, optionsJson, callbackName)`，stdout 按行合并，在 exit 时验证 JSON；共享启动与状态读取在后台等待。当前 APatch、KernelSU、KsuWebUI 的三参数 exec 虽带回调，执行阶段仍同步阻塞，Promise 不能消除这段阻塞。无 spawn 的旧宿主保持 exec 兼容，可能仍有等待卡顿，建议更新宿主；已提交操作失败或超时绝不改用另一接口重试。历史行与分组减少重复渲染，日期格式器复用，长返回内容展开时加载，自动同步保留展开状态。每页仍显示 100 条，存储上限仍为 1000。验证入口 `tests/navigation-regression.html` 使用实际 App 和模拟原生 spawn，检查共享／状态等待期间切页和历史更新，不进入生产 ZIP。详见 [验证说明](../docs/webui-response-0.3.24-validation.md)。

0.3.23：历史恢复保留最新 1000 条，每页默认显示 100 条；较长记录通过有界分批读取合并为完整显示页，翻页不会跳过记录。展开显示对应手机的标准输出、标准错误、协议状态和可用退出码，每条返回合计最多 4096 字节并标注截断。搜索包含返回内容；同一请求的结果变化也会静默同步。无退出码不推断成功，旧记录不伪造输出。只读展示可观察的 adb 请求，不还原电脑端不可见参数、不记录 APK／文件载荷、认证材料或交互输入。0.3.22 曾误将保存上限设为 100 条，已纠正；下方是历史版本说明，当前行为以本条为准。

0.3.20：底栏为设备 / 连接 / 历史 / 设置，历史从连接页移出，采用整页滚动。显示可读 adb 表达和安装阶段，详情保留实际请求；无法看到的电脑端路径或调用参数明确说明。搜索匹配显示命令与全部保留记录，新记录上限为 4096 字符，分页按响应字节预算自动缩小。

0.3.19：首次点击共享时的窗口焦点事件不再清空有效 USB 调试检测结果，避免按钮在 click 前被禁用。focus / pageshow 只触发静默更新；visibilitychange / pagehide 仍使结果失效，过期或失败仍禁止开启。浏览器回归入口 `tests/focus-regression.html` 使用模拟客户端检查实际 React 控件，不连接原生桥接或手机；这些测试文件不进入生产 ZIP。

0.3.18：首页删除 adbd Root 开关和相关状态、API 与预览分支。保留 USB 调试及 WebUI 控制 Shell UID 的只读检测，明确本机 WebUI 授权不代表远程 ADB 已有 Root。普通共享不受旧 Root 切换状态影响。

0.3.16：历史按安装应用、应用管理、Shell、文件、调试、系统、网络分类；安装阶段单独标明创建会话、写入 APK、提交／放弃等。筛选与搜索查询全部最近 1000 条，支持结果分页，复用已有状态观察刷新最新筛选结果。请求不代表执行成功。旧格式历史升级保留，详情保留原始脱敏请求。

0.3.15：共享开关新增 USB 调试前置检查（页面状态 + 守护进程重新读取），系统关闭、检测未知或过期不能开启；已有开启状态仍能关闭。显式预览 `?preview=1&usb=1&debug=off` / `debug=unknown` 可查看禁止开启状态。

2026-11-03：首页新增“调试与权限”分组，包含系统 USB 调试检测、WebUI 控制 Shell UID 检测与重新检测入口。Shell Root 授权由管理器控制，不能通过保存一个偏好自行授予或撤销。检测只在首页可见时每 15 秒更新。当前本地模块版本 0.3.18，尚未真机验收或发布 GitHub。

2026-11-02：界面按 AppOpt 当前 Android Compose 风格重写，使用蓝白主题、渐变设备概览、白色圆角分组及固定底栏。保留藏蓝深色适配和原有三页功能；设计来源与验证范围见 [设计记录](DESIGN.md)。已本地打包为 0.3.13 USB ADB 模块，尚未刷入真机或发布 GitHub。

Magisk / APatch / KernelSU 模块内的中文手机界面；Magisk 通过独立 KsuWebUI 应用打开，需授予它 Root 权限。依赖根项目现有 React、Vite 与 Fluent 图标，不另安装依赖。

在仓库根目录执行：

```powershell
node node_modules/vite/bin/vite.js --config mobile/webui/vite.config.mjs
node node_modules/vite/bin/vite.js build --config mobile/webui/vite.config.mjs
node --test mobile/webui/tests/*.test.mjs
```

本地交互预览：`http://127.0.0.1:5174/?preview=1`。预览状态只在内存中，始终显示预览横幅。没有 `preview=1` 的普通浏览器显示模块环境不可用，不模拟成功。

构建输出在 `mobile/webui/dist`，打包时放入模块 `webroot`。

0.3.9 保持现有蓝白／藏蓝布局，界面标识改为通用 Root 模块。KsuWebUI 与 APatch／KernelSU 共用三参数 `ksu.exec(command, optionsJson, callbackName)`，回调为 `(errno, stdout, stderr)`。不按宿主名称猜测能力，不退回同步执行，不在失败／超时后重发操作；没有桥接时说明三种打开方式。授权被拒绝或模块未启用时不展示成功，不泄露原始 shell 输出。源码核对与主机测试不替代 Android WebView 真机验证。

0.3.8 的 adbd Root 开关、API 和示例已移除。

0.3.7 在连接页新增远程 ADB 历史，保留三页导航。最新 20 条复用现有轻量状态快照自动同步，不新增 app_process 轮询；手动“查看更早记录”才调用 Root 控制接口 `history`，以记录 ID 与后台代际分页。`clear-history` 经确认、串行执行并等待保存，返回当前状态；旧轮询不能恢复已清空的记录。历史内容只作为文本显示，不写浏览器存储，不作为 shell 参数或可执行链接。示例预览：`?preview=1&usb=1&history=1`，普通浏览器不能生成真实历史或控制手机。

0.3.6 的设备／连接页显示“最近一次连接中断”。这是当前后台进程保留的历史诊断，不代表此刻断开；当前状态仍以会话列表与新鲜观察为准。原生数据包含固定原因、时间、诊断码和已完成字节数，不包含调试命令、载荷或配对秘密。带 `preview=1&usb=1&interruption=1` 的显式预览可查看诊断展示；没有 `preview=1` 不会生成模拟状态。

普通查询经 `usblinkctl status` 读取后台的原子状态文件，核对进程身份、启动周期及 10 秒时效，不再启动 Java 客户端。变更仍走 Root 本地控制套接字，成功响应直接用于页面，旧轮询结果不得覆盖它。共享及准备状态每 2 秒、关闭状态每 5 秒轮询，失败逐步退避；隐藏页面停止查询。未变化的状态复用已有 React 数据，不重绘整页。

0.3.4 起，共享关闭时网络显示“已断开”，保留已保存的配对信息；不会把主动断网显示成一直连接或错误。只有开启共享才连接，创建／加入网络时默认只保存配置；“退出网络”仍需确认并清除配对。空闲后台观察也降为每 5 秒，操作后立即唤起观察。

原生桥接优先使用 APatch / KernelSU / KsuWebUI 注入的 `window.ksu.spawn(command, '[]', '{}', callbackName)`，旧版仅有 exec 时维持三参数回调契约。只允许固定操作名；载荷以 UTF-8 JSON 的 Base64 字符串传入固定 `usblinkctl`，没有原始用户内容拼接到 shell。返回格式为 `{ "ok": true, "data": ... }` 或 `{ "ok": false, "error": "..." }`。

网络配对码不写入 Web Storage，离开连接页即清空已显示的码与输入。调试使用系统 adbd TCP 和 Android RSA 电脑授权，已移除无线调试的配对窗口、端口发现和手动配对端口。界面区分保存的共享意愿与实际就绪状态；关闭共享需等待后端恢复原调试配置，失败时提供“关闭共享并重试恢复”。切换前可见提示说明会重启 adbd，可能中断已有调试连接。
