# Windows 0.3.17 连接页重写

采用手机 WebUI / AppOpt 的蓝白与藏蓝主题，重新组织整个连接工作流：

- `ConnectionPage.jsx` 独立负责网络概览、添加／管理网络、页签、共享 USB 与本机挂载的呈现。原后台回调、身份校验与互斥机制继续使用，不启动其他 ADB 或重试挂载。
- `NetworkDevices.jsx` 改为可搜索的来源列表，当前来源就地展开 USB；收起、搜索和切换页签只改变视图。没有设备数量上限。
- “已连接”页签集中展示所有来源的挂载、实际确认状态和单设备断开。来源不可达不妨碍提交本地断开。
- 新增独立 `connections.css`，移除旧连接界面的 142 条专用样式；批量栏仅在选中 USB 或连接操作进行中出现。

定向验证：

- 19 项既有来源隔离、认证状态、USB 身份和挂载快照检查通过，未重复运行全量后端测试。
- 浏览器示例中，连接两个来源相同 `99-1` 编号的手机，在“已连接”查看两条记录；单独断开第一台后第二台保留。
- 验证按行连接、勾选后批量栏、批量连接后清空选择、页签切换、搜索／清除、离线来源提示、添加设备面板和空状态返回入口。
- 1180×760 默认窗口与 820×600 最小窗口检查；最小窗口无页面／挂载行横向溢出，单设备断开按钮保持 84px。截图在 `release/verification-0.3.17/`。
- Vite、Rust、NSIS 构建通过；应用版本 0.3.17，安装包复制前后 SHA-256 一致。

本次为浏览器示例、定向逻辑检查和构建验证，没有安装新程序、操作真实 USB 或验证远程传输。深色主题沿用变量并提供独立规则，未在真实 WebView 深色环境验收。手机模块未更改，仍为 0.3.15；未推送或发布 GitHub。
