# Windows 0.3.16 连接页排版修复

截图中的状态竖排来自 `.connection-detail .device-status`：该选择器同时命中了共享列表和已挂载列表，将后者状态放到 40px 图标列并增加 30px 左边距。

本次将远程列表样式限定到 `.remote-device-panel`，挂载状态使用独立 `.mount-status`，并把型号、来源与端口放在可伸缩的信息列。状态徽标整体换行，断开按钮保持独立宽度。来源标题、提示和共享列表合并为一组；已连接区明确包含所有来源。

定向验证：

- Vite / Rust / NSIS 安装程序构建通过，应用版本 0.3.16；安装包复制后 SHA-256 一致。
- 浏览器示例连接两台不同来源、相同 `99-1` 编号的手机；切换来源保留两条挂载；断开第一台后第二台仍在。
- 1280×720 与 820×600 预览均显示横向状态；820px 下挂载行和页面无横向溢出，徽标高度 22px、断开按钮宽度 88px。
- `git diff --check` 无空白错误；截图位于 `release/verification-0.3.16/`。

仅更新桌面界面和版本信息；未安装新程序、操作真实 USB、重启 ADB 或测试真实远程传输。手机模块仍为 0.3.15。本次未运行全量后端测试或发布 GitHub。
