# Windows 0.3.12 多设备网络验证

日期：2026-10-16。本次为本地 Windows 构建，尚未推送或发布 GitHub 版本。

## 行为与迁移

- 手机和电脑使用同一个 USBLink 配对码加入网络；软件不设置成员或共享 USB 数量上限，实际容量受网络、操作系统和虚拟 USB 驱动资源约束。
- 原先各自创建网络的手机，需要退出各自旧网络、加入电脑保留的共同网络一次。以后只需在“连接 → 同一网络的设备”选择来源；切换查看不会退出网络、重新配对或断开其他来源的挂载。
- 显示来源名称、地址、经过认证的在线状态和该来源的挂载数量；支持搜索、多个来源同时挂载、逐设备断开及断开全部。
- 手机共享开关仍控制其网络上下线；此次电脑端更新不要求重新刷模块。掉线后依然需要用户手动点击连接。

## 实现检查

- USB 导出快照绑定来源地址；请求序号与当前来源双重检查阻止迟到响应覆盖新来源。
- 勾选身份包含来源地址、总线号和 VID/PID。切换来源、设备身份变化、设备消失或已经挂载时，旧勾选不再有效。
- 挂载数量按来源地址统计；不同手机相同的 `99-1` / `18d1:4ee7` 不合并。挂载操作仍使用现有后端的串行、唯一一次 `--once` 流程；逐设备断开仍校验来源、总线号、VID/PID 与本机端口。
- EasyTier 成员发现未添加数量截断；现有每批 8 个认证探测仅控制并发，不是成员上限。

## 已完成的验证

- `npm test`：23 项通过。新增覆盖 80 个混合成员、320 个跨来源同号 USB、搜索、离线来源保留、来源切换和勾选身份变化。
- `cargo test --manifest-path src-tauri/Cargo.toml --offline`：90 项通过、4 项忽略。新增 80 成员解析测试；忽略项未执行真机挂载。
- `npm run tauri:build`：前端生产构建及 Windows x64 NSIS 中文安装包生成成功。
- 浏览器 `?multi=1` 使用 12 个明确标注的示例来源。验证了 3 台同号 USB 手机同时保留、切换来源保留挂载、定向断开一台保留另外两台、名称／地址搜索及清除、离线来源禁止连接而本机挂载仍可断开。
- 验证了按勾选连接、切换来源清空勾选、添加成员指引和取消退出网络确认；这些操作未调用真实驱动、ADB 或更改手机配置。
- 在 820×600 和 1180×760 浏览器视口检查布局，无页面横向溢出；小窗口可滚动并通过键盘到达设备操作。新增样式使用已有深色主题变量，未进行深色模式截图验收。

## 验证边界

浏览器示例和合成数据测试不等于真实多手机压力测试。本次未启动安装后的 Windows 程序、安装新包、连接真实手机、刷模块或更改已有网络，因此尚未验证多机同时传输、长时间连接与实际驱动容量。

安装包：`release/USBLink-0.3.12-x64-Setup.exe`，附同名 `.sha256` 文件。
