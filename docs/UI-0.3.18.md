## 修复

- 现场只读 EasyTier 发现结果中，K70 当前为 10.126.126.3，截图残留的 .5 已不在列表中。原前端把历次 IP 永久累加；现在成功发现后使用本次成员列表，仅发现失败时保留旧行并标为离线。真实驱动挂载仍独立保留在“已连接”中。
- 同一 IP 的旧 Android 类型仅在当前 mesh peer ID 相同时作为离线显示提示保留。peer ID 不是永久手机身份，不按型号合并，也不据此重挂载。
- 管理网络、添加设备均提供显示／复制配对码；面板收起、页面切换和窗口隐藏时清除显示，延迟返回不能重新显示已经隐藏的码。只在用户请求时向后端获取，不持久化到前端。
- 手机底栏调整为设备 / 连接 / 历史 / 设置；历史从连接页移出，列表使用整页滚动。
- 历史显示 adb shell、adb exec-out 等可读表达。adb install / adb uninstall 为操作分类，保留创建／写入／提交等实际请求阶段；展开可看原始脱敏请求。ABB 参数中的空格通过引号保留。
- 最大记录由 512 扩为 4096 字符；OPEN 请求最多读取 4096 字节，超限标记截断。每页至多 20 条且记录 JSON 合计不超过 40,000 字节，给 64 KiB 控制响应留下空间。存储最多 1000 条，读取上限 16 MiB，旧历史保留。未搜索时不对全量长命令做大小写转换。
